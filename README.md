# 서울 아파트 신고가 트래커

https://raspos.github.io/seoul-apartment-tracker/

국토교통부 공개 실거래 자료의 조회용 스냅샷입니다. 2021년 이후 동일 단지·전용면적 내림 그룹으로 비교합니다. 게시 기준일은 화면에 표시합니다.

Python 로컬 프로젝트의 export_pages.py로 검증·생성한 공개 파일만 게시합니다. API 인증키·환경파일·SQLite DB·작업 로그는 포함하지 않습니다. 자료 갱신과 임의 기준일 분석은 로컬 서버에서 실행합니다.

출처: https://www.data.go.kr/data/15126468/openapi.do
